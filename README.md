THE WORLD TODAY is a 1024×1024 newspaper front page for Monday 23 November 2026, drawn entirely in code by a Node 22 program with no network and no external images. The lead story is NATO's extraordinary council meeting in Brussels today after three Russian weapons came down in south-east Poland, beside a hand-drawn map of the three impact sites; below it sit six more stories from the day — COP31 collapsing with no deal in Antalya, Iran striking Bahrain, a drone flattening part of a Kyiv-region apartment block with 14 still missing, the FT linking Alice Huang to a chip-smuggling network, the EU and Indonesia signing their landmark trade deal, and Bolsonaro in intensive care — with a latest-news ticker and a sources footer. Every fact comes from reporting dated 20–23 November 2026, verified against at least two sources each.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output/`). Two runs produce byte-identical output.
